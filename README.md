# uvl-inventory-offboard

### Setup:
1. `git clone https://github.com/uvl-robotics/uvl-inventory-offboard`
2. `cd inventory-offboard`
3. `npm i`
4. `./generate_env.sh > .env` and change it according to your setup

### Common radio setup

```
radio6 - buttons
  2006 - none
  1067 - empty
  1249 - rescan
  1495 - notag
   982 - unread

radio7 - photo
   982 - no
  2006 - press
```
