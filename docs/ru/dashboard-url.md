# Настройка доступа к Dashboard по URL

## Обзор

По умолчанию dashboard доступен по IP адресу Raspberry Pi (например, `http://192.168.1.100:8080`). Для удобства можно настроить доступ по доменному имени (URL), например `http://uvl-photo.local:8080`.

## Быстрая настройка (рекомендуется)

### Автоматическая настройка при установке

Скрипт настройки DNS автоматически запускается при `npm install`, если у вас есть права root:

```bash
sudo npm install
```

Если вы запускаете `npm install` без sudo, скрипт пропустит настройку DNS и выведет инструкции.

### Ручная настройка

Если автоматическая настройка не сработала, запустите скрипт вручную:

**Вариант 1 (через npm):**
```bash
sudo npm run setup-dns
```

**Вариант 2 (напрямую):**
```bash
cd /path/to/uvl_photo_project
sudo ./tools/setup-dns.sh
```

### Что делает скрипт

Скрипт автоматически:
- Установит и настроит avahi-daemon
- Изменит hostname на `uvl-photo`
- Настроит mDNS для домена `uvl-photo.local`
- Установит и настроит nginx как reverse proxy на порту 80
- Добавит переменную `DASHBOARD_HOSTNAME=uvl-photo.local` в `.env`
- Перезапустит необходимые сервисы

После выполнения скрипта перезапустите приложение:
```bash
sudo systemctl restart offboard
```

Dashboard будет доступен по адресу: `http://uvl-photo.local` (без указания порта, nginx проксирует на порт 8080)

## Варианты настройки

### Вариант 1: Использование mDNS (рекомендуется для локальной сети)

mDNS (multicast DNS) позволяет использовать доменные имена вида `<hostname>.local` в локальной сети без дополнительной настройки DNS сервера.

#### Настройка на Raspberry Pi

1. **Проверьте hostname Raspberry Pi:**
   ```bash
   hostname
   ```

2. **Если нужно изменить hostname:**
   ```bash
   sudo hostnamectl set-hostname mydrone
   ```

3. **Убедитесь, что avahi-daemon установлен и запущен:**
   ```bash
   sudo apt-get update
   sudo apt-get install avahi-daemon
   sudo systemctl enable avahi-daemon
   sudo systemctl start avahi-daemon
   ```

4. **Установите переменную окружения в `.env`:**
   ```env
   DASHBOARD_HOSTNAME=mydrone.local
   ```
   (замените `mydrone` на ваш hostname)

5. **Перезапустите приложение:**
   ```bash
   sudo systemctl restart offboard
   ```

#### Использование

После настройки dashboard будет доступен по адресу:
- `http://mydrone.local:8080` (если указан `DASHBOARD_HOSTNAME=mydrone.local`)
- Или просто `http://<hostname>.local:8080` (работает автоматически, даже без переменной окружения)

**Примечание:** mDNS работает только в локальной сети и требует поддержки на клиентском устройстве (Windows 10+, macOS, Linux).

### Вариант 2: Использование локального DNS сервера

Если у вас есть локальный DNS сервер (например, на роутере или отдельном сервере), можно настроить запись для Raspberry Pi.

1. **Настройте DNS запись** на вашем DNS сервере:
   - Имя: `mydrone` (или любое другое)
   - Тип: A
   - Значение: IP адрес Raspberry Pi (например, `192.168.1.100`)

2. **Установите переменную окружения в `.env`:**
   ```env
   DASHBOARD_HOSTNAME=mydrone
   ```
   (или `mydrone.example.com`, если используется поддомен)

3. **Перезапустите приложение:**
   ```bash
   sudo systemctl restart offboard
   ```

### Вариант 3: Использование публичного домена

Если у вас есть публичный домен и вы хотите сделать dashboard доступным из интернета:

1. **Настройте DNS запись** у вашего DNS провайдера:
   - Имя: `mydrone` (или поддомен)
   - Тип: A
   - Значение: Публичный IP адрес вашего роутера

2. **Настройте port forwarding** на роутере:
   - Порт 8080 → IP адрес Raspberry Pi:8080

3. **Установите переменную окружения в `.env`:**
   ```env
   DASHBOARD_HOSTNAME=mydrone.example.com
   ```

4. **Перезапустите приложение:**
   ```bash
   sudo systemctl restart offboard
   ```

**Внимание:** Публичный доступ требует настройки безопасности (HTTPS, аутентификация, firewall).

## Проверка настройки

После настройки проверьте:

1. **В логах приложения** должно появиться сообщение:
   ```
   [dashboard]: Доступен по адресу: http://mydrone.local:8080
   ```

2. **В интерфейсе dashboard** в верхней части страницы должен отображаться доменный адрес вместо IP.

3. **Попробуйте открыть dashboard** по новому адресу в браузере.

## Отображение в интерфейсе

Если переменная `DASHBOARD_HOSTNAME` установлена, в интерфейсе dashboard будет отображаться доменное имя вместо IP адреса. Если доменное имя не указано, будет отображаться IP адрес.

## Примечания

- WebSocket автоматически использует тот же hostname, что и HTTP запрос (через `location.hostname`), поэтому дополнительная настройка не требуется.
- Если доменное имя не разрешается, браузер может показать ошибку. В этом случае можно временно использовать IP адрес.
- Для работы mDNS на Windows может потребоваться включить службу "Служба обнаружения SSDP" и "Служба публикации обнаружения функций".
