# Переменные окружения (.env)

Полный список всех переменных окружения, которые можно настроить в файле `.env`.

## Общие параметры

### `DRONE_ID`
- **Описание**: ID дрона (используется для идентификации в системе)
- **По умолчанию**: `00`
- **Пример**: `DRONE_ID=01`

### `DASHBOARD_HOSTNAME`
- **Описание**: Доменное имя для доступа к dashboard (например: `uvl-photo.local`). Если указано, будет использоваться вместо IP адреса для отображения в интерфейсе. Для работы требуется настройка DNS или mDNS (выполняется скриптом `tools/setup-dns.sh`)
- **По умолчанию**: не установлено
- **Пример**: `DASHBOARD_HOSTNAME=uvl-photo.local`

## MAVLink настройки

### `MAVLINK_SERIAL_PATH`
- **Описание**: Путь к последовательному порту MAVLink
- **По умолчанию**: `/dev/ttyACM0`
- **Пример**: `MAVLINK_SERIAL_PATH=/dev/ttyUSB0`

### `MAVLINK_SERIAL_BAUD`
- **Описание**: Скорость порта MAVLink
- **По умолчанию**: `57600`
- **Пример**: `MAVLINK_SERIAL_BAUD=115200`

### `MAVLINK_SYSTEM_ID`
- **Описание**: ID системы MAVLink
- **По умолчанию**: `1`
- **Пример**: `MAVLINK_SYSTEM_ID=1`

### `MAVLINK_UDP_EN`
- **Описание**: Включить UDP для MAVLink (позволяет подключаться через Mission Planner по сети)
- **По умолчанию**: `false`
- **Пример**: `MAVLINK_UDP_EN=true`

### `MAVLINK_UDP_HOST`
- **Описание**: Хост UDP для MAVLink
- **По умолчанию**: `0.0.0.0` (все интерфейсы)
- **Пример**: `MAVLINK_UDP_HOST=0.0.0.0`

### `MAVLINK_UDP_PORT`
- **Описание**: Порт UDP для MAVLink (стандартный порт Mission Planner)
- **По умолчанию**: `14550`
- **Пример**: `MAVLINK_UDP_PORT=14550`

## Сканер и OSD (On-Screen Display)

### `SCANNER_SERIAL_PATH`
- **Описание**: Путь к последовательному порту сканера
- **По умолчанию**: `/dev/ttyAMA0`
- **Пример**: `SCANNER_SERIAL_PATH=/dev/ttyAMA0`

### `SCANNER_SERIAL_BAUD`
- **Описание**: Скорость порта сканера
- **По умолчанию**: `115200`
- **Пример**: `SCANNER_SERIAL_BAUD=115200`

### `SCANNER_SERIAL_RECONNECT_TIMEOUT`
- **Описание**: Таймаут переподключения сканера в миллисекундах (0 = отключено)
- **По умолчанию**: `0`
- **Пример**: `SCANNER_SERIAL_RECONNECT_TIMEOUT=5000`

### `OSD_SERIAL_PATH`
- **Описание**: Путь к последовательному порту OSD (если не указан, используется `SCANNER_SERIAL_PATH`)
- **По умолчанию**: значение `SCANNER_SERIAL_PATH`
- **Пример**: `OSD_SERIAL_PATH=/dev/ttyAMA0`

### `OSD_SERIAL_BAUD`
- **Описание**: Скорость порта OSD (если не указана, используется `SCANNER_SERIAL_BAUD`)
- **По умолчанию**: значение `SCANNER_SERIAL_BAUD`
- **Пример**: `OSD_SERIAL_BAUD=115200`

### `OSD_WIDTH`
- **Описание**: Ширина экрана OSD (в символах)
- **По умолчанию**: `30`
- **Пример**: `OSD_WIDTH=30`

### `OSD_HEIGHT`
- **Описание**: Высота экрана OSD (в символах)
- **По умолчанию**: `16`
- **Пример**: `OSD_HEIGHT=16`

### `OSD_PADDING_TOP`
- **Описание**: Верхний отступ OSD (в символах)
- **По умолчанию**: `1`
- **Пример**: `OSD_PADDING_TOP=1`

### `OSD_PADDING_BOTTOM`
- **Описание**: Нижний отступ OSD (в символах)
- **По умолчанию**: `5`
- **Пример**: `OSD_PADDING_BOTTOM=5`

### `OSD_PADDING_LEFT`
- **Описание**: Левый отступ OSD (в символах)
- **По умолчанию**: `2`
- **Пример**: `OSD_PADDING_LEFT=2`

### `OSD_PADDING_RIGHT`
- **Описание**: Правый отступ OSD (в символах)
- **По умолчанию**: `2`
- **Пример**: `OSD_PADDING_RIGHT=2`

## RC каналы (Radio Control)

### Номера каналов

#### `RC_EMPTY_CH`
- **Описание**: Номер канала для кнопки EMPTY
- **По умолчанию**: `6`

#### `RC_RESCAN_CH`
- **Описание**: Номер канала для кнопки RESCAN
- **По умолчанию**: `6`

#### `RC_NO_TAG_CH`
- **Описание**: Номер канала для кнопки NO_TAG
- **По умолчанию**: `6`

#### `RC_UNREADABLE_CH`
- **Описание**: Номер канала для кнопки UNREADABLE
- **По умолчанию**: `6`

#### `RC_PHOTO_CH`
- **Описание**: Номер канала для кнопки PHOTO (основная функция - фотографирование)
- **По умолчанию**: `7`
- **Пример**: `RC_PHOTO_CH=7`

#### `RC_SCANOFF_CH`
- **Описание**: Номер канала для кнопки SCANOFF
- **По умолчанию**: `8`

#### `RC_ALLEY_SWITCH_CH`
- **Описание**: Номер канала для переключения аллей
- **По умолчанию**: `9`

### PWM значения

#### `RC_EMPTY_PWM`
- **Описание**: PWM значение для кнопки EMPTY
- **По умолчанию**: `1067`

#### `RC_RESCAN_PWM`
- **Описание**: PWM значение для кнопки RESCAN
- **По умолчанию**: `1249`

#### `RC_NO_TAG_PWM`
- **Описание**: PWM значение для кнопки NO_TAG
- **По умолчанию**: `1495`

#### `RC_UNREADABLE_PWM`
- **Описание**: PWM значение для кнопки UNREADABLE
- **По умолчанию**: `982`

#### `RC_PHOTO_PWM`
- **Описание**: PWM значение для кнопки PHOTO (значение при нажатии)
- **По умолчанию**: `2006`
- **Пример**: `RC_PHOTO_PWM=2006`

#### `RC_SCANOFF_PWM`
- **Описание**: PWM значение для кнопки SCANOFF
- **По умолчанию**: `2006`

#### `RC_ALLEY_NEXT_PWM`
- **Описание**: PWM значение для переключения на следующую аллею
- **По умолчанию**: `1025`

#### `RC_ALLEY_PREV_PWM`
- **Описание**: PWM значение для переключения на предыдущую аллею
- **По умолчанию**: `1075`

## Камера и фотографирование

### `CAMERA_EN`
- **Описание**: Включить камеру
- **По умолчанию**: `false`
- **ОБЯЗАТЕЛЬНО**: Установите в `true` для работы фотографирования
- **Пример**: `CAMERA_EN=true`

### `PHOTO_WIDTH`
- **Описание**: Ширина фотографии (пиксели)
- **По умолчанию**: `2028`
- **Пример**: `PHOTO_WIDTH=2028`

### `PHOTO_HEIGHT`
- **Описание**: Высота фотографии (пиксели)
- **По умолчанию**: `1520`
- **Пример**: `PHOTO_HEIGHT=1520`

### `CAMERA_FRAMERATE`
- **Описание**: Частота кадров камеры (FPS)
- **По умолчанию**: `10`
- **Пример**: `CAMERA_FRAMERATE=10`

### `PHOTO_EXIF_ORIENTATION`
- **Описание**: Ориентация EXIF (1-8). Для значений см. [документацию CIPA](http://www.cipa.jp/std/documents/e/DC-008-2012_E.pdf)
- **По умолчанию**: `6`
- **Пример**: `PHOTO_EXIF_ORIENTATION=6`

### `CAMERA_TIMEOUT`
- **Описание**: Таймаут камеры в миллисекундах (0 = бесконечно)
- **По умолчанию**: `0`
- **Пример**: `CAMERA_TIMEOUT=0`

## Настройки экспозиции камеры

### `CAMERA_SHUTTER`
- **Описание**: Выдержка в микросекундах (0 = автоматическая, максимум 100000000)
- **По умолчанию**: `0`
- **Пример**: `CAMERA_SHUTTER=10000` (10 миллисекунд)

### `CAMERA_GAIN`
- **Описание**: Усиление gain (0 = автоматическая, диапазон 0-16)
- **По умолчанию**: `0`
- **Пример**: `CAMERA_GAIN=2`

### `CAMERA_EXPOSURE`
- **Описание**: Режим экспозиции
- **По умолчанию**: `normal`
- **Допустимые значения**: `normal`, `short`, `long`
- **Пример**: `CAMERA_EXPOSURE=normal`

### `CAMERA_METERING`
- **Описание**: Режим замера экспозиции
- **По умолчанию**: `centre`
- **Допустимые значения**: `centre`, `spot`, `matrix`, `custom`
- **Пример**: `CAMERA_METERING=centre`

### `CAMERA_AWB`
- **Описание**: Баланс белого
- **По умолчанию**: `auto`
- **Допустимые значения**: `auto`, `incandescent`, `tungsten`, `fluorescent`, `indoor`, `daylight`, `cloudy`, `custom`
- **Пример**: `CAMERA_AWB=auto`

## Сохранение фотографий

### `PHOTO_SAVE_ENABLED`
- **Описание**: Включить сохранение фотографий на диск
- **По умолчанию**: `false`
- **Пример**: `PHOTO_SAVE_ENABLED=true`

### `PHOTO_SAVE_DIR`
- **Описание**: Директория для сохранения фотографий (создаётся автоматически, если не существует)
- **По умолчанию**: `./photos`
- **Пример**: `PHOTO_SAVE_DIR=./photos`

## Минимальная конфигурация для работы

Для базовой работы фотографирования достаточно следующих параметров:

```env
# Включить камеру
CAMERA_EN=true

# Путь к последовательному порту MAVLink
MAVLINK_SERIAL_PATH=/dev/ttyACM0

# Путь к последовательному порту OSD
OSD_SERIAL_PATH=/dev/ttyAMA0

# RC канал для кнопки фотографирования
RC_PHOTO_CH=7
RC_PHOTO_PWM=2006
```

## Создание файла .env

### Вариант 1: Использование примера конфигурации (рекомендуется)

В корне проекта есть файл `env.example` с полным примером всех параметров:

```bash
cp env.example .env
```

Затем отредактируйте файл `.env` и установите нужные значения под вашу систему.

### Вариант 2: Использование скрипта (Linux/Mac)

```bash
chmod +x tools/generate_env.sh
./tools/generate_env.sh > .env
```

Затем отредактируйте файл `.env` и установите необходимые значения.

### Вариант 3: Ручное создание

Создайте файл `.env` в корне проекта и скопируйте нужные параметры из этой документации или из файла `env.example`.

## Примечания

- Все параметры опциональны и имеют значения по умолчанию
- Параметры камеры можно изменять динамически через веб-интерфейс dashboard
- Изменения параметров камеры сохраняются в файл `camera-config.json` и применяются при следующем запуске
- Для работы с камерой обязательно установите `CAMERA_EN=true`
- Для подключения через Mission Planner установите `MAVLINK_UDP_EN=true`
