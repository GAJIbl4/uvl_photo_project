# Скрипт настройки DNS для dashboard

## Описание

Скрипт `setup-dns.sh` автоматически настраивает DNS для доступа к dashboard по доменному имени `uvl-photo.local` вместо IP адреса.

## Использование

### Автоматический запуск при npm install

Скрипт автоматически пытается запуститься при `npm install`, но только если у вас есть права root:

```bash
sudo npm install
```

Если вы запускаете `npm install` без sudo, скрипт пропустит настройку DNS и выведет инструкции.

### Ручной запуск

#### Вариант 1: Через npm script (рекомендуется)

```bash
sudo npm run setup-dns
```

#### Вариант 2: Напрямую через bash скрипт

```bash
cd /path/to/uvl_photo_project
sudo ./tools/setup-dns.sh
```

#### Вариант 3: Через Node.js обертку

```bash
sudo node tools/setup-dns.js
```

## Что делает скрипт

1. **Устанавливает avahi-daemon** (если не установлен)
   - avahi-daemon обеспечивает работу mDNS (multicast DNS)
   - Позволяет использовать доменные имена `.local` в локальной сети

2. **Изменяет hostname** на `uvl-photo`
   - Обновляет системный hostname через `hostnamectl`
   - Обновляет файл `/etc/hosts`

3. **Настраивает avahi-daemon**
   - Создает конфигурационные файлы для HTTP (порт 8080) и WebSocket (порт 8081)
   - Перезапускает avahi-daemon для применения изменений

4. **Устанавливает и настраивает nginx**
   - Устанавливает nginx (если не установлен)
   - Создает конфигурацию reverse proxy на порту 80
   - Проксирует HTTP запросы на порт 8080
   - Проксирует WebSocket запросы (/ws) на порт 8081
   - Позволяет использовать dashboard без указания порта

5. **Настраивает переменную окружения**
   - Добавляет или обновляет `DASHBOARD_HOSTNAME=uvl-photo.local` в файле `.env`

6. **Проверяет настройку**
   - Проверяет, что hostname установлен правильно
   - Проверяет, что avahi-daemon запущен
   - Проверяет, что nginx запущен
   - Проверяет, что переменная окружения установлена

## После выполнения скрипта

1. **Перезапустите приложение:**
   ```bash
   sudo systemctl restart offboard
   ```
   Или если запускаете вручную:
   ```bash
   node index.js
   ```

2. **Откройте dashboard в браузере:**
   ```
   http://uvl-photo.local
   ```
   (порт указывать не нужно, nginx автоматически проксирует на порт 8080)

## Требования

- Права root (sudo)
- Raspberry Pi OS или другой Linux дистрибутив
- Доступ к интернету для установки пакетов (при первом запуске)

## Примечания

- Для работы mDNS на клиентских устройствах:
  - **Windows**: Включите службу "Служба обнаружения SSDP" и "Служба публикации обнаружения функций"
  - **macOS/Linux**: mDNS обычно работает из коробки

- Если доменное имя не разрешается, проверьте:
  - Что avahi-daemon запущен: `sudo systemctl status avahi-daemon`
  - Что hostname установлен: `hostname` (должно быть `uvl-photo`)
  - Что устройства находятся в одной локальной сети

- После изменения hostname может потребоваться перезагрузка системы для полного применения изменений (особенно для некоторых сетевых служб)

## Откат изменений

Если нужно вернуться к использованию IP адреса:

1. Удалите или закомментируйте строку `DASHBOARD_HOSTNAME=uvl-photo.local` в файле `.env`
2. Перезапустите приложение

Для полного отката всех изменений (hostname, avahi):
- Измените hostname обратно: `sudo hostnamectl set-hostname <старый-hostname>`
- Удалите файлы конфигурации avahi: `sudo rm /etc/avahi/services/dashboard-*.service`
- Перезапустите avahi-daemon: `sudo systemctl restart avahi-daemon`
